# Pilot Roadmap

## Phase 1: Simulation Control Twin

- Run Unity, FastAPI, and Streamlit locally.
- Validate the end-to-end workflow with sample images and NASA-inspired health records.
- Demonstrate policy changes, manual overrides, and digital product passports.

## Phase 2: Lab-Scale Cell

- Replace the simple classifier with a trained YOLO/ResNet model.
- Add battery damage detection.
- Add thermal camera input.
- Add voltage/internal resistance measurements from bench instruments.
- Connect a small robot or gantry through ROS 2.
- Add OPC UA/PLC interface for conveyor and safety state.

## Phase 3: Dubai Partner Pilot

- Add real Dubai fleet, recycler, or service center data.
- Replace CSV/JSON logs with a database.
- Add user authentication and operator audit trails.
- Add VR/AR operator interface for metaverse manufacturing control.
- Integrate downstream reporting for circularity metrics and recovered value.
