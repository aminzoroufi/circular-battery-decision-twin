# Project Naming

## Candidate Names

1. Circular Battery Decision Twin
2. Battery Lifecycle Routing Twin
3. Circular Battery Recovery Lab
4. Battery Recovery Decision Framework
5. Battery Lifecycle Control Sandbox

## Selected Name

**Circular Battery Decision Twin**

This name is specific enough for GitHub and portfolio use without claiming that the prototype is a finished industrial product. It reflects the actual repository: a local Unity, FastAPI, and Streamlit system for exploring circular battery recovery decisions, routing logic, operator control, and traceability.

The older internal folder, Unity project, and class names are kept where renaming could break Unity references.
